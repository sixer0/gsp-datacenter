## 5. Tantangan terhadap keputusan yang sudah diambil

- **D-108 / D-87 (resolver tunggal)** — Klaim "11 keluarga + core tanpa penanganan alias sendiri" benar untuk kunci parameter, tidak benar untuk alias aksen (#1). D-87 sendiri menetapkan "sumber aksen: medan accent > params alias > flag data"; H2 melanggar (gabungan), K1 melanggar sebagian (per medan), dan sembilan keluarga lain membuang alias tanpa REPORT. Usul: perluas IP-25 agar resolver juga menormalkan alias aksen.
- **D-50 (deteksi Mermaid lebih ketat)** — Lebih ketat menghasilkan penolakan 422 atas kalimat biasa (#6). Pengetatan sebaiknya pada posisi (awal baris / di luar nilai string), bukan pada huruf.
- **D-106 (paritas byte-identik build diagram)** — Paritas juga mengunci cacat lint Python: DATUM-25 lulus untuk 6 nilai warna (#2). Paritas bukan bukti kebenaran lint; usul deviasi tercatat.
- **D-108 (DATUM-28 toleransi 1e-3 pt; tambalan +0,005 pt H2 dihapus)** — Benar dan terverifikasi: font ditulis 5 desimal mm (`chart/core/svg.ts:187`), galat <= 1,5e-4 pt; baseline 0 FAIL DATUM-28 pada 90 render. Tetapi toleransi tidak menolong ketika lantai dinaikkan (#5).
- **D-77 (gaya datum = parameter eksplisit saja)** — Diimplementasikan dua kali (`family-p1/common.ts:145`, `family-s2/common.ts:150`) dengan definisi "eksplisit" = nilai templat yang berbeda dari default registri; nilai templat yang sengaja disetel sama dengan default tidak terbedakan. Dapat diterima, tetapi sebaiknya satu definisi di inti (#8).
- **D-41, D-42, D-82, D-89** — Tidak ada bukti yang menentang. D-89 (multi-bus ditolak default, opt-in `sld.multiBus`) konsisten di `diagram/layout-c/sld.ts:1-45`; D-82 statistik (quantile7, Sturges, Silverman/Scott) konsisten di `family-s1/stats.ts`.
